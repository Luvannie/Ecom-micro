4. Cart Service - Redis Data Store

cart-service Primary Data Store Port 8084

Cart Service sử dụng Redis như primary data store cho shopping carts. Thay vì lưu trong database, carts được lưu hoàn toàn trong Redis với TTL 30 ngày.

4.1 CartRepository Implementation

BE/cart-service/src/main/java/com/ecom/cart/repository/CartRepository.java 
package com.ecom.cart.repository;

import com.ecom.cart.domain.Cart;
import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Repository;

import java.time.Duration;
import java.util.Optional;
import java.util.UUID;

@Repository
public class CartRepository {
    // TTL: 30 days - cart data expires after this period
    private static final Duration TTL = Duration.ofDays(30);

    private final StringRedisTemplate redisTemplate;
    private final ObjectMapper objectMapper;

    // Constructor injection via Spring
    public CartRepository(StringRedisTemplate redisTemplate, ObjectMapper objectMapper) {
        this.redisTemplate = redisTemplate;
        this.objectMapper = objectMapper;
    }

    // Find cart by userId - key pattern: "cart:{userId}"
    public Optional<Cart> findByUserId(UUID userId) {
        String value = redisTemplate.opsForValue().get(key(userId));
        if (value == null) {
            return Optional.empty();
        }
        try {
            return Optional.of(objectMapper.readValue(value, Cart.class));
        } catch (JsonProcessingException exception) {
            throw new IllegalStateException("Unable to read cart " + userId, exception);
        }
    }

    // Save cart with 30-day TTL
    public Cart save(Cart cart) {
        try {
            redisTemplate.opsForValue().set(
                key(cart.getUserId()),
                objectMapper.writeValueAsString(cart),
                TTL
            );
            return cart;
        } catch (JsonProcessingException exception) {
            throw new IllegalStateException("Unable to write cart " + cart.getUserId(), exception);
        }
    }

    // Delete cart by userId
    public void deleteByUserId(UUID userId) {
        redisTemplate.delete(key(userId));
    }

    // Key generation: "cart:{userId}"
    private String key(UUID userId) {
        return "cart:" + userId;
    }
}
✓ Key Points:
  • Sử dụng StringRedisTemplate để lưu JSON string
  • ObjectMapper serialize/deserialize Cart object
  • Key pattern: cart:{userId}
  • TTL: 30 days - tự động xóa sau 30 ngày không hoạt động

4.2 CartService - Business Logic

BE/cart-service/src/main/java/com/ecom/cart/service/CartService.java 
package com.ecom.cart.service;

import com.ecom.cart.client.ProductClient;
import com.ecom.cart.client.ProductSnapshot;
import com.ecom.cart.repository.CartRepository;
import org.springframework.stereotype.Service;

import java.util.UUID;

@Service
public class CartService {
    private final CartRepository cartRepository;
    private final ProductClient productClient;

    public CartService(CartRepository cartRepository, ProductClient productClient) {
        this.cartRepository = cartRepository;
        this.productClient = productClient;
    }

    // Get cart - create new if not exists
    public Cart getCart(UUID userId) {
        return cartRepository.findByUserId(userId)
            .orElseGet(() -> new Cart(userId));
    }

    // Add item to cart
    public Cart addItem(UUID userId, UUID productId, int quantity) {
        validateQuantity(quantity);
        Cart cart = getCart(userId);
        cart.addOrUpdate(snapshot(productId), quantity);  // Get fresh product snapshot
        return cartRepository.save(cart);
    }

    // Update quantity or remove if quantity = 0
    public Cart updateQuantity(UUID userId, UUID productId, int quantity) {
        if (quantity < 0 || quantity > 99) {
            throw new InvalidCartQuantityException();
        }
        Cart cart = getCart(userId);
        if (quantity == 0) {
            cart.remove(productId);
        } else {
            cart.updateQuantity(snapshot(productId), quantity);
        }
        return cartRepository.save(cart);
    }

    // Remove single item
    public Cart removeItem(UUID userId, UUID productId) {
        Cart cart = getCart(userId);
        cart.remove(productId);
        return cartRepository.save(cart);
    }

    // Clear entire cart
    public void clear(UUID userId) {
        cartRepository.deleteByUserId(userId);
    }

    // Get product snapshot from ProductService via Feign
    private ProductSnapshot snapshot(UUID productId) {
        ProductSnapshot product = productClient.getProduct(productId);
        if (product == null || !product.active()) {
            throw new ProductUnavailableException(productId);
        }
        return product;
    }

    private void validateQuantity(int quantity) {
        if (quantity < 1 || quantity > 99) {
            throw new InvalidCartQuantityException();
        }
    }
}

4.3 Cart Domain Model

BE/cart-service/src/main/java/com/ecom/cart/domain/Cart.java 
package com.ecom.cart.domain;

import com.ecom.cart.client.ProductSnapshot;
import java.math.BigDecimal;
import java.time.Instant;
import java.util.ArrayList;
import java.util.List;
import java.util.UUID;

public class Cart {
    private UUID userId;
    private List<CartItem> items = new ArrayList<>();
    private Instant updatedAt;

    // Synchronized access for thread safety
    public synchronized void addOrUpdate(ProductSnapshot product, int quantity) {
        for (int i = 0; i < items.size(); i++) {
            CartItem item = items.get(i);
            if (item.getProductId().equals(product.id())) {
                item.refresh(product, Math.min(99, item.getQuantity() + quantity));
                return;
            }
        }
        items.add(new CartItem(product, quantity));
        touch();
    }

    // Remove item by productId
    public synchronized void remove(UUID productId) {
        items.removeIf(item -> item.getProductId().equals(productId));
        touch();
    }

    // Calculate total price
    public synchronized BigDecimal total() {
        return items.stream()
            .map(CartItem::subtotal)
            .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    private void touch() { updatedAt = Instant.now(); }

    // Getters and setters...
}
💡 Design Decisions:
  • Thread Safety: Sử dụng synchronized methods để tránh race conditions
  • Product Snapshot: Lưu product data tại thời điểm thêm vào cart (không rely on live prices)
  • JSON Serialization: Cart được serialize thành JSON string trong Redis
  • Quantity Limits: Mỗi item tối đa 99 units

5.2 Cacheable Methods

BE/product-service/src/main/java/com/ecom/product/service/ProductCatalogService.java 
package com.ecom.product.service;

// ... imports ...

@Service
@Transactional
public class ProductCatalogService {
    private final CategoryRepository categoryRepository;
    private final ProductRepository productRepository;

    // Cache Evict: Xóa cache khi có thay đổi
    @CacheEvict(cacheNames = {"product-detail", "product-search"}, allEntries = true)
    public ProductResponse createProduct(CreateProductRequest request) {
        Category category = findCategory(request.categoryId());
        Product product = new Product(category, request.name(), request.slug(),
                         request.description(), request.price(), request.imageUrl(), request.promotionTag());
        return toProductResponse(productRepository.save(product));
    }

    @CacheEvict(cacheNames = {"product-detail", "product-search"}, allEntries = true)
    public ProductResponse updateProduct(UUID productId, UpdateProductRequest request) {
        Product product = productRepository.findById(productId)
            .orElseThrow(() -> new ProductNotFoundException(productId));
        // ... update logic ...
        return toProductResponse(product);
    }

    @CacheEvict(cacheNames = {"product-detail", "product-search"}, allEntries = true)
    public ProductResponse changeStatus(UUID productId, boolean active) {
        Product product = productRepository.findById(productId)
            .orElseThrow(() -> new ProductNotFoundException(productId));
        product.setActive(active);
        return toProductResponse(product);
    }

    // Cacheable: Kết quả được cache lại
    @Cacheable(
        cacheNames = "product-search",
        key = "#p0.toCacheKey() + ':' + #p1.pageNumber + ':' + #p1.pageSize"
    )
    @Transactional(readOnly = true)
    public Page<ProductSummaryResponse> search(ProductSearchCriteria criteria, Pageable pageable) {
        return productRepository.findAll(specification(criteria), pageable)
            .map(this::toProductSummary);
    }

    // Cacheable: Cache by productId
    @Cacheable(
        cacheNames = "product-detail",
        key = "#p0"
    )
    @Transactional(readOnly = true)
    public ProductResponse getProduct(UUID productId) {
        return productRepository.findByIdAndActiveTrue(productId)
            .map(this::toProductResponse)
            .orElseThrow(() -> new ProductNotFoundException(productId));
    }
}

6. Design Patterns

6.1 Repository Pattern (Cart Service)

Cart Service sử dụng Repository pattern để trừu tượng hóa Redis operations: 

// CartRepository encapsulates all Redis operations
// Caller (CartService) doesn't know about Redis implementation

@Repository
public class CartRepository {
    private final StringRedisTemplate redisTemplate;

    public Optional<Cart> findByUserId(UUID userId) { ... }
    public Cart save(Cart cart) { ... }
    public void deleteByUserId(UUID userId) { ... }
}
✓ Benefits:
  • Separation of concerns - business logic không phụ thuộc vào Redis API
  • Dễ test - có thể mock CartRepository
  • Dễ thay đổi storage backend nếu cần

6.2 Declarative Caching (Product Service)

Sử dụng Spring's @Cacheable và @CacheEvict annotations để declarative cache management: 

// Cache result of this method
@Cacheable(cacheNames = "product-detail", key = "#p0")
public ProductResponse getProduct(UUID productId) {
    // Only executes if cache miss
    return productRepository.findByIdAndActiveTrue(productId)...;
}

// Evict all entries from these caches
@CacheEvict(cacheNames = {"product-detail", "product-search"}, allEntries = true)
public ProductResponse createProduct(...) {
    // Cache evicted after this method succeeds
}

6.3 TTL-based Expiration

Cart data có TTL 30 days - tự động cleanup nếu user không quay lại: 

private static final Duration TTL = Duration.ofDays(30);

public Cart save(Cart cart) {
    redisTemplate.opsForValue().set(
        key(cart.getUserId()),
        objectMapper.writeValueAsString(cart),
        TTL   // Redis automatically deletes after 30 days
    );
    return cart;
}

6.4 Thread Safety

Cart class sử dụng synchronized methods để đảm bảo thread safety khi nhiều requests cùng modify cart: 

public class Cart {
    // Synchronized access prevents race conditions
    public synchronized void addOrUpdate(ProductSnapshot product, int quantity) {
        // Critical section
    }

    public synchronized void remove(UUID productId) { ... }
    public synchronized BigDecimal total() { ... }
}

6.5 Product Snapshot Pattern

Khi thêm item vào cart, product data được snapshot (copy) để không phụ thuộc vào live product data: 

public Cart addItem(UUID userId, UUID productId, int quantity) {
    // Get current product data via Feign client
    ProductSnapshot product = productClient.getProduct(productId);

    // Store snapshot in cart - independent of future product changes
    cart.addOrUpdate(product, quantity);
    return cartRepository.save(cart);
}

User sends POST /cart/items

Get or create Cart
